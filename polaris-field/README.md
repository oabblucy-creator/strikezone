# 北極星 · POLARIS — 夜間空地持刀場景

單一檔案的 3D 第一人稱場景：夜晚的空地（極光、北極星、小北斗、樹線、木柵欄、三個稻草靶），
手上拿著三角洲風格的「北極星」OTF 彈簧刀。

## 怎麼玩
線上版：https://oabblucy-creator.github.io/strikezone/polaris-field/ （第二個世界；第一個世界是 https://oabblucy-creator.github.io/strikezone/ ）
本機：直接雙擊 `index.html` 就能開（需要連網，Three.js 從 CDN 載入）。

| 按鍵 | 動作 |
|---|---|
| 點畫面 | 開始（手舉起來、喀一聲出刀） |
| WASD / Shift / 空白鍵 | 移動 / 衝刺 / 跳 |
| 左鍵 | 揮刀：砍①右上→左下 → 砍②左下→右上 → 刺（連按三下）；停手後會自動做收刀小動作（轉拇指 / 指間轉 / 拋刀）再「鏘」出刀 |
| F（或右鍵） | 耍刀（三角洲式）：收刀 → 手指一根根張開、刀繞拇指轉兩圈（手指輪流撥刀） → 拋刀翻兩圈、手指依序收攏接住 → 手腕一甩「鏘」出刀 |
| R | 收刀 / 出刀（北極星） |
| 1 / 2（或 Q） | 換刀：北極星 ↔ 信條（三角洲的指虎匕首，**反手握持**：刀尖朝左下、四根手指穿過指孔、拇指包住尾端；大馬士革鋼、火焰倒刺刀背、血槽、白骨指虎、黃銅護手、紅寶石徽章、尾端鏈條）。信條三段＝① 指虎重拳 ② 反手橫掃 ③ 回掃（50/35/35），紅色刀光；F＝翻手看指孔與紅寶石 → 指虎直拳 |
| Esc | 離開滑鼠鎖定 |

砍稻草靶會噴火花、留下斬痕、衝擊光環、靶子會晃，準心會閃命中標記、飄傷害數字（照三角洲北極星：30 / 30 / 42），
命中瞬間有定格＋鏡頭震動。每根手指都是三節關節（指根／中節／指尖）會一節一節伸直、彎曲：砍的時候會張開再握緊、轉刀時輪流撥刀、拋刀時依序彈開／收攏，
待機時還會自己敲敲握把、拇指搓推鈕、重新握緊。靶子 100 血，一套連段（30+30+42）就會整個炸開、頭飛出去，2.6 秒後重生。左下角計命中數。

## 檔案
- `index.html` — 全部程式（場景、刀模、動畫、特效、音效）都在這一檔，沒有外部素材
- `serve.py` — 開發用預覽伺服器（`python serve.py 8160`），支援 `POST /save?name=xxx` 存截圖
